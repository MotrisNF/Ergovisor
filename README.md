# RAG against the machine: workplace posture analysis

Work in progress. The system analyses a video of a person working: a pose
model draws their skeleton, the code measures their postures against the
occupational risk prevention limits, and the RAG explains each result with
the regulation and technical guides it comes from.

The documentation of the original RAG project (the vLLM question answering
system this one starts from) is kept in [original_docs/](original_docs/).
